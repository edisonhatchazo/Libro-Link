# libro_link

LibroLink is an application designed to provide a comprehensive digital platform for managing, exploring, and interacting with books. The app allows users to search for books, view detailed descriptions, explore books on Google Books, and manage their own personalized library of favorite books. With seamless navigation, intuitive UI, and support for dark and light modes, LibroLink enhances the user's reading and book management experience.
